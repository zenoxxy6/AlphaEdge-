# AlphaEdge MVP

AlphaEdge is a mobile-first market-analysis and risk-management dashboard.

## Included
- Dashboard
- Demo market pulse chart
- Stock analyzer with deterministic demo signal engine
- Candlestick-pattern labels
- RSI/MACD/trend indicators
- RiskGuard position sizing
- Multi-currency display (INR/USD/EUR/GBP)
- Opportunity scanner
- Money tracker
- Trade history
- Responsive mobile UI
- No backend required for the MVP

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

## Important
The analyzer currently uses demo calculations and demo market data. Replace it with a licensed/authorized market-data API before using live prices. Do not treat generated signals as guaranteed outcomes or financial advice.
